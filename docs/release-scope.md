# Scope and remaining decisions

## Included

- Executed A/B/C/D source snapshots, fixed model/tokenizer configurations, frozen selection/group/pair and donor manifests, and recorded environment identities.
- Nine-model score projections and native pair effects sufficient for the released CPU commands; original layer/token/window/control distinctions and the primary versus total-logprob endpoints are preserved.
- Separate representation-probe folds/out-of-fold scores, compact boundary vectors and a CPU refit entry point for the eight-model canonical interface panel; ProcessBench scores/pair identities, and verification baseline, decision flip and normalized-gap analyses.
- Current-paper tables/figures, their source/data map and portable generators where recovered.
- Public file hashes, concise CPU validation receipts and original-paper artifact identities labelled separately.

## Intentionally omitted

- Model weights, full activation archives beyond the selected probe boundary vectors, caches, installed packages and third-party font files.
- Raw dataset problem/solution text, including rendered prompt text stored in behavior records. The public projection retains the recorded input hashes and scores. Reconstruct inputs from the pinned upstream datasets using the documented preparation commands and verify their identities.
- Private Git history/remotes, author/contact and local-machine paths, cloud-management/credentials, internal audits, prompts, conversations and collaboration records.
- Unused historical experiments and smoke results. Some legacy utilities exist inside the preserved execution packages because those modules form the actual snapshot; they are not additional paper evidence.

## Boundaries

The CPU checks validate archived scientific results and portable processing. Fresh canonical probe fits additionally match the saved OOF scores for seven models; GLM has explicitly reported reference differences, including a maximum AUROC difference of 0.0003092, with the exact cause unresolved. They do not establish a fresh end-to-end GPU reproduction. A full GPU run needs compatible hardware, separately acquired model weights and the campaign-specific dependencies. Original atomic files/activations are not all distributed: projections explicitly say which fields survive and which checks were performed previously versus repeated here.

Historical `sha256` values nested in archived results identify their original source files. Sanitized public bytes use the root `MANIFEST.json`; those identities must not be conflated. No protected validation split was used by the intervention analyses.

See `secondary/README.md` for the retained GPT-OSS-120B probe wrapper's version discrepancy, successful fixed-input CPU refit, and exact feature-bundle coverage. The original wrapper bytes have not been recovered. See `paper/README.md` for figure/table equivalence (scientific values versus PDF/TeX bytes) and fonts/tool requirements.

The original project code and author-generated artifacts are supplied under the review-use permission in `LICENSES.md`. The project-level package metadata matches this scope; these review materials are not an MIT release. Upstream dataset/model licenses remain separate. A later public release may adopt an open-source license.
